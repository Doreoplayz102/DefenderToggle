Hello, This is DefenderToggle this is an opensource but vibecocded
project to ensure pc safety.

The use case of this is to disable antivirus thoroughly if you are
a computer engineer or simply have an app that needs the anti
virus to be fully disabled(assuming and hoping its not a virus lol).
This can also be used if realtime was disabled by an admin even though
you are. You do not need to turn off tamper protection just to enable
antivirus, you only need to turn off tamper protection to throughly 
disable it (clicking the disable button).

project holding malicious intent. This was a project because
